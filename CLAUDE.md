# Claude Code Agent Instructions

This file provides context and instructions for Claude code agents working in this repository.

## Project Overview

This is a workspace for building a potential app. The project is in early stages, so the tech stack and architecture are still being decided.

## Repository Structure

- `app/` — Main application source code
  - `src/` — Source files

## Development Guidelines

- Keep code clean, readable, and well-documented.
- Prefer simple, incremental changes over large rewrites.
- Write tests alongside new features.
- Discuss architecture decisions before making large structural changes.

## Getting Help

When working on this project, Claude agents should:
1. Read existing code before making changes.
2. Ask clarifying questions if requirements are ambiguous.
3. Suggest improvements and alternatives where appropriate.
4. Keep the user informed of progress and any blockers.
